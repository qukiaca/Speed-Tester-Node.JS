# Speed-Tester-Node.JS

Данный проект является простым скриптом на Node.js для измерения скорости загрузки данных по HTTP/HTTPS.

Программа несколько раз загружает указанный ресурс, измеряет время выполнения каждого запроса и рассчитывает скорость передачи данных.

## Возможности
- Загрузка данных по HTTP и HTTPS.
- Выполнение нескольких последовательных запросов.
- Измерение времени загрузки каждого запроса.
- Расчёт скорости передачи данных для каждого запроса.
- Подсчёт общего объёма загруженных данных.
- Расчёт средней скорости загрузки.
- Обработка ошибок HTTP-запросов и тайм-аутов.

## Требования
- [Node.js](https://nodejs.org/) версии **18 или новее**.
- Подключение к интернету.

Дополнительные npm-пакеты не требуются.

## Запуск
Клонирование репозитория:

```bash
git clone https://github.com/qukiaca/Speed-Tester-Node.JS.git
cd ./Speed-Tester-Node.JS
```

Запуск скрипта, указав URL ресурса для загрузки:

```bash
node speedtest.js 'https://example.com/file'
```


По умолчанию программа выполняет **10 последовательных запросов**. Тайм-аут одного запроса составляет **30 секунд**.

## Единицы измерения
В программе используются следующие единицы измерения:

| Обозначение | Значение |
|---|---|
| `B` | Байт |
| `KiB` | Кибибайт (1024 байта) |
| `MiB` | Мебибайт (1024 KiB) |
| `ms` | Миллисекунда (1/1000 секунды) |
| `Mbps` | Мегабит в секунду (1 000 000 бит/с) |

Скорость передачи данных рассчитывается в мегабитах в секунду по формуле:
```text
Speed (Mbps) = (Bytes × 8) / (Time (ms) × 1000)
```

Средняя скорость рассчитывается на основе общего объёма загруженных данных и суммарного времени успешных запросов.

## Примечания

- Запросы выполняются последовательно, а не параллельно.
- Измеренное время включает ожидание ответа сервера и загрузку тела ответа.
- На результат могут влиять задержка сети, производительность сервера и особенности соединения.
- При загрузке небольших файлов результат может быть менее показательным из-за влияния сетевых задержек.
